# Yilin 7A English Lesson Plan Skill
译林版牛津七年级英语教案生成技能
> 面向学科教学（英语）研究生、初中英语教师，一键生成标准化 Markdown 教案，适配义务教育英语新课标。

## 📌 简介
本技能专门针对 **译林版牛津初中英语 7A（七年级上册）**，支持6种常规课型：
- Welcome to the unit
- Reading
- Grammar
- Integrated skills
- Study skills
- Task

输出为结构固定的 Markdown 教案，GitHub、Obsidian、语雀均可正常渲染，可直接用于微格教学、作业提交、备课参考。
设计依托：英语学科四大核心素养（语言能力、文化意识、思维品质、学习能力），常用 PWP / TBLT 教学模式。

## ✨ 快速上手
1. 复制本仓库 `prompt.md` 里面的提示词
2. 修改提示词底部参数：单元、板块、课时、补充需求
3. 发给AI，直接获得 Markdown 教案
4. 复制结果保存为 `.md` 文件即可
